# 갯벌의 하루

초등학교 3학년 과학 수업에서 갯벌의 가치를 알아보기 위한 스토리형 웹앱입니다.

학생들은 아침부터 저녁까지 이어지는 여섯 장면을 살펴보고, 간단한 조작과 확인 문제를 통해 갯벌이 하는 일을 알아봅니다.

## 주요 내용

- 다양한 생물이 살아가는 삶터
- 철새의 먹이터와 쉼터
- 사람에게 제공하는 먹거리와 생활 자원
- 물속 오염 물질을 줄이는 기능
- 파도와 물의 힘을 줄이는 기능
- 휴식과 생태 관찰을 위한 공간

## 웹앱 실행

인터넷 배포 전에는 `index.html` 파일을 브라우저에서 열어 확인할 수 있습니다.

GitHub Pages로 배포한 뒤에는 다음 주소로 접속합니다.

```text
https://깃허브아이디.github.io/저장소이름/
```

## GitHub Pages 배포

자세한 방법은 [DEPLOY.md](DEPLOY.md)를 확인하세요.

이 프로젝트는 정적 웹앱이므로 별도의 설치, 빌드, `npm` 명령이 필요하지 않습니다.

## 파일 구성

```text
index.html       웹앱 실행 파일
assets/          이미지, 음원, 영상
DEPLOY.md        GitHub Pages 배포 방법
CREDITS.md       사용 자료의 출처 기록
.nojekyll        GitHub Pages 정적 배포 설정
```
