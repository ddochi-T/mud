# 갯벌의 하루 — GitHub Pages 단일 파일 배포본

초등학교 3학년 과학 수업에서 갯벌의 가치를 알아보는 스토리형 웹앱입니다.

이미지·음원·영상이 모두 `index.html` 안에 포함되어 있어 `assets` 폴더가 필요하지 않습니다. 별도의 설치나 빌드도 없습니다.

## 실행 방법

- 컴퓨터에서 확인: `index.html`을 브라우저로 엽니다.
- 인터넷에 배포: [DEPLOY.md](DEPLOY.md)의 안내에 따라 GitHub Pages를 켭니다.

## 압축을 푼 뒤의 파일 구성

```text
index.html       웹앱과 모든 미디어가 들어 있는 실행 파일
README.md        웹앱 안내
DEPLOY.md        GitHub Pages 배포 방법
CREDITS.md       사용 자료의 출처 기록
.nojekyll        GitHub Pages 정적 배포 설정
```

> 가장 중요한 확인 사항: GitHub 저장소 첫 화면에 `index.html`이 바로 보여야 합니다.

## 참고

단일 파일 방식은 경로 오류가 생기지 않는 대신 `index.html`의 용량이 약 18MB여서 첫 실행 때 약간 기다릴 수 있습니다.
